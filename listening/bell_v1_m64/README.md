# Bell V1 M6.4 listening pack (local, unversioned audio)

These WAVs are deterministic renders generated by the M6.4 host run
(`tests/test_dsp.cpp::testBellM64ListeningPack`). They are kept locally for
critical listening and are intentionally **not** versioned (the repository
ignores `*.wav`; regenerate with `ctest --test-dir build-host -R dsp`).

Candidates:

- `*_A_*` — production baseline `kPresetBell`
- `*_B_*` — baseline with tierce gain 0.58
- `*_C_*` — hum 0.24 / tierce 0.58 / nominal 0.90

Start with the `*_matched.wav` A/B/C files (loudness-normalized to A):

- `bell_m64_abc_D4_v70_{A,B,C}_matched.wav`
- `bell_m64_abc_D4_v110_{A,B,C}_matched.wav`
- `bell_m64_abc_chord4_{A,B,C}_matched.wav`
- `bell_m64_abc_roll_{A,B,C}_matched.wav`

Baseline character and tails:

- `bell_m64_note_{36,48,55,60,67,72,84}_v90.wav`
- `bell_m64_single_{48,60,72}_v{30,60,90,110,127}.wav`
- `bell_m64_interval_*.wav`, `bell_m64_chord4_v*.wav`, `bell_m64_poly8_v*.wav`
- `bell_m64_restrike_*.wav`, `bell_m64_roll.wav`

Per-file metrics and reference hashes: `bell_m64_listening_pack.md`.
Procedure and decision rules: `docs/bell_v1_listening_pack.md`.
