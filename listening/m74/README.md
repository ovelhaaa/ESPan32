# MARIMBA M7.4 listening pack

Decision OPEN; A is provisional runtime, not a frozen winner.

A: warm modal bar only. B: same bar plus subtle body. C: moderately brighter bar,
reduced body. Listen to *_matched.wav for equal RMS comparisons, then raw files
for actual playing levels. Each trio shares one RMS target. See
[configuration and qualification](../../docs/m74_marimba.md) and
[SHA256 manifest](../../docs/qualification/m74_wav_manifest.json).

Start with D3_v70, D4_v70, D4_v110, chord, roll, roll_steady.
All five registers and v30/70/110/127, cluster8, 100/250 ms restrikes and
voice-steal burst are included. WAVs are generated local artifacts (ignored by Git);
run test_dsp in build-host to regenerate and copy marimba_*.wav here.
