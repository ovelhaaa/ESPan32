## 6. Objective safety (Phase G)

Every generated fixture asserts on the host:

```text
hard clamp = 0
NaN / Inf  = 0
max active voices <= 8
```

Measured baseline pack: hard clamp 0, modal saturation 0, all samples finite.
The four-note chord and eight-note polyphony reached pre-limiter peaks up to
~4.7 with up to ~13.9 dB limiter gain reduction and no hard clamp.
